## 第一阶段：安全与可靠性（高优先级）

### 1. 正式登录与权限管理

- [ ] 选择 JWT 或 OIDC 方案，从可信认证结果生成用户、组织和角色上下文。
- [ ] 不再接受客户端请求头直接指定身份或权限。
- [ ] 将会话、上传文件、知识库及长期记忆归属统一绑定可信身份。
- [ ] 明确匿名访问规则及多组织隔离策略。

验收：伪造用户与角色请求头不能提升权限；跨用户访问、跨组织访问均被拒绝；现有自己的会话可正常继续。

### 2. 写操作审批与审计

- [ ] 统一声明工具的读写属性和权限要求。
- [x] 写操作生成可查看的待审批内容，批准后执行（主代理及子代理中间件 + 前端审批卡片）。
- [x] 审批绑定用户、组织、会话、调用 ID 和参数摘要，支持拒绝、5 分钟过期及取消。
- [x] 增加单进程调用去重及落盘审计，重复批准返回冲突。
- [ ] 将审批状态与幂等记录迁移到共享持久化存储，支持多 worker、进程重启恢复与历史归档。

当前实现说明：未声明的业务及 MCP 工具默认需要审批；受信业务代码可通过工具 metadata.approval_mode=read_only 标记只读，MCP 外部 metadata 不作为免审批依据。已有工具权限校验保留，批准不会提升角色权限。待审批任务在运行中的调用内等待，重启失效；审计仅保留身份、工具、摘要、时间和状态，不存完整参数。身份仍来自请求头，正式鉴权仍待完成。

2026-10-03 验证：批准、拒绝、过期、取消、跨用户/组织、参数变化、重复批准、审计失败、真实工具图等待及接口回归均通过；真实后端生成本地 Word 测试文件经历 pending → approved → executing → completed。

验收：未批准的写操作无法执行；参数变化后需要重新批准；可查询审批与执行结果。

### 3. 初始化与资源生命周期

- [ ] 将沙箱、checkpointer、MCP 和 Agent 构建纳入失败清理范围。
- [ ] 逐项隔离关闭异常，按依赖逆序关闭业务资源与底层连接。
- [ ] 验证部分初始化、启动失败、重复关闭及正常退出场景。

验收：任一步初始化失败后，已打开连接、子进程及后台线程均被回收；单个关闭异常不影响其余清理。

### 4. 长期记忆与技能加载

- [ ] 统一 /memorise/ 与 /memories/ 路径，明确旧数据兼容策略。
- [ ] 为技能提供只读 Backend 路由或预置文件，核对 SDK 要求的目录层级。
- [ ] 验证技能 metadata 实际加载，而非仅记录目录名称。
- [ ] 验证长期记忆跨会话、重启后保留，且用户与组织之间隔离。

验收：可在运行状态确认技能加载结果；用户记忆持久化且不串用户；不可读取技能目录外的文件。

## 第二阶段：执行控制与知识能力（中优先级）

### 5. 任务执行控制

- [ ] 设置整轮任务超时、工具超时和递归限制。
- [ ] 增加用户级并发限制和同一会话并发保护。
- [ ] 记录模型 usage，设置 Token 与费用预算，明确超限行为。
- [ ] 建立任务状态与失败分类，重试仅针对可安全重试的操作。

验收：超时或超额能终止任务并清晰反馈；同一会话并发不会覆盖历史；重试不重复产生外部副作用。

### 6. 中断、人工介入与恢复（先验证现有能力）

- [ ] 验证前端停止是否传播到服务端、模型请求及工具执行。
- [ ] 定义客户端断开连接后的任务处理策略。
- [ ] 支持人工审批暂停、继续执行，并验证重启后恢复。

验收：停止后不会继续无界执行；审批恢复保持原会话与授权上下文；历史不丢失或重复。

### 7. 知识库管理与可核对引用

- [ ] 明确 RagWiki 与本项目的文档入库、解析、索引更新职责。
- [ ] 补充文档权限过滤、来源标识、版本及可打开的引用。
- [ ] 处理重复上传、文档删除和索引失效。

验收：检索不能返回无权访问的文档；引用可以核对原文；更新或删除后索引一致。

### 8. 可观测性与评测

- [ ] 消除重复日志，统一字段、级别与脱敏规则。
- [ ] 关联请求、会话、模型调用和工具调用，接入链路追踪。
- [ ] 汇总耗时、失败率、Token 与费用，配置告警。
- [ ] 建立评测样本，覆盖检索质量、引用正确性、工具选择和权限拒绝。

验收：可追踪一轮对话完整调用链；敏感信息不进入日志；可对比版本质量与成本。
