1. 招商项目研判 Agent

这个比“拜访准备”更像一个真正的业务 Agent。

例如招商主管收到一个新项目：

某新能源企业计划投资 3 亿元建设储能设备生产基地，想判断这个项目值不值得重点跟进。

以前需要人工分别查询企业工商信息、企业经营情况、产业方向、项目投资数据、园区准入条件和相关扶持政策，再写项目研判材料。

Agent 可以自动完成：

用户提交项目材料
        ↓
解析企业 / 项目信息
        ↓
企业信息 Tool
        ↓
历史招商数据 Tool
        ↓
产业匹配 Tool
        ↓
园区准入规则 Tool
        ↓
政策 RAG
        ↓
风险分析
        ↓
项目评分
        ↓
生成招商研判报告

最后输出：

企业是否符合园区产业方向
项目投资强度是否达标
预计产值、税收是否合理
有哪些政策可以匹配
存在哪些风险
是否建议进入重点招商项目

这个场景非常好，因为它同时有：

信息查询 + RAG + Tools + 规则计算 + LLM 综合判断。

而且面试官问：

为什么需要 Agent？

你很好回答：

因为招商项目研判不是一个固定接口能完成，它需要根据项目情况动态调用企业信息、产业匹配、政策检索、准入评估等多个能力，再综合生成结论。

我认为这个甚至可以作为你简历中的主 Agent 场景。
